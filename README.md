# CineScope — Movie Review App

A responsive React, Vite, and Tailwind CSS movie browser using mock data. No API key required.

## Features
- Search by movie title
- Filter by genre, year, and community rating
- Sort by popularity, rating, newest, or oldest
- Detail modal with synopsis, cast, director, release date, and runtime
- Interactive 1–5 star user ratings saved in localStorage
- Responsive design and graceful poster-image fallbacks

## Run locally
Requires Node.js 18+.

```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Netlify
Import the GitHub repository. Build command: `npm run build`. Publish directory: `dist`.
